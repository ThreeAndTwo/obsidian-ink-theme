# Changelog

## 0.0.2 — 2026-10-06

- Replace all 15 documented Tasks metadata emoji and its edit/postpone actions with distinct embedded monochrome outlines.
- Apply task symbols in Reading, Live Preview, Source mode and query results while preserving body and monospace text fonts.
- Style dates consistently, distinguish priority levels and keep completed/cancelled urgency quiet.
- Preserve short-mode layout, long metadata wrapping, original Markdown, task dates and native click handlers.
- Remove the broad completed-task image filter so unrelated emoji images retain their authored appearance.
- Installation remains two files: `manifest.json` and `theme.css`.

## 0.0.1 — 2026-10-05

First public release of ink by ThreeAndTwo, licensed under MIT.

- Light paper and dark charcoal palettes with an optional subtle dot grid.
- Centered reading, system body fonts, serif page titles and a dotted current-line indicator.
- Distinct links, bold text, highlights and neutral inline code.
- Markdown, tasks, tables, callouts, diagrams, Canvas and Bases styles.
- Two-file theme installation package.
- Original user-provided note screenshots with documented version boundaries.

Release numbering starts at 0.0.1. GitHub release tags, the theme manifest and installation packages use the same version.
