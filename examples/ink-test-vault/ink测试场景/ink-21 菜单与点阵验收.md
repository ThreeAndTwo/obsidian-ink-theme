# 菜单与点阵验收

Markdown 文件不能替代原生设置页或系统菜单。请在真正的 Obsidian 界面执行下面的步骤。

## 点阵

1. 切换到浅色，打开 [[ink-空白笔记]]。
2. 查看纸面中规律的淡点阵；再打开 [[ink-01 中文长文]]，查看正文周围留白。
3. 分别切换阅读、实时预览、源码，比较背景覆盖。
4. 切换深色，重复检查。

代码块、菜单、输入框和内容卡片维持实色表面，点阵主要用于笔记纸面。打印或系统高对比会移除纸面纹样。

## 下拉框

1. 设置 → 外观，打开主题下拉框。
2. 已选项应有勾选符号和选中底色。
3. 把鼠标移到另一项，悬停底色应比选中底色淡，两项不应连成同色的大块。
4. 用键盘选择、确认或取消，检查焦点与值的变化。
5. 如已装插件，进入一个插件普通弹窗，查看下拉框是否采用相同的单箭头和普通字体。

## 菜单

在文件树右键一篇笔记，或打开视图操作菜单。查看正常、悬停、禁用、带警告的项目和快捷键。

macOS 系统绘制的原生菜单不能由 CSS 修改；要检查主题菜单，在 设置 → 外观 关闭“原生菜单”。独立测试库已关闭；复制场景文件夹到已有库不会修改已有设置。
