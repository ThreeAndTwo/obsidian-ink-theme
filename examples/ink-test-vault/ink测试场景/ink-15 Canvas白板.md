# Canvas 白板

直接打开 [[ink-场景白板.canvas]]。下面也嵌入同一份真实白板：

![[ink-场景白板.canvas]]

白板包含文本卡片、实际 Markdown 文件卡片、SVG 图片卡片、分组和连线。

## 操作检查

- 拖动卡片、缩放和移动画布。
- 选择一张卡片，查看选中边界。
- 双击文字卡片进入编辑，输入一行字。
- 调整一张卡片大小，拖动连线端点。
- 点击文件卡片，打开对应笔记。
- 检查背景点阵、普通字体、小色条和浅色/深色切换。

画布保存的布局来自 `.canvas` 文件。主题只改变其外观，不伪造拖动控件。
