# Markdown 基础样式

普通正文、**粗体**、*斜体*、***粗斜体***、~~删除线~~、==高亮== 和 `行内代码`。

同一行比较：普通说明、**重要结论**、==需要复习的内容==、`文件路径` 和 [外部链接](https://obsidian.md)。

组合强调：**`重要参数`**，==`重点代码`==，==**高亮的重要结论**==。代码不应占用链接的赭红，也不应盖住作者主动添加的粗体或高亮。

## 检查点

- 一级到六级标题有顺序明确的层级。
- 斜体中文可能受系统字体支持影响；不应出现奇怪装饰字体。
- 浅色/深色：链接赭红、代码中性底、粗体墨色与高亮金色底有各自用途，不能全部抢用同一强调色。
- 阅读视图隐藏标记；实时预览在光标所在处允许显示标记。
- 注释在源码可见，在阅读视图隐藏。
